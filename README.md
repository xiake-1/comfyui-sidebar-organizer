# ComfyUI Sidebar Organizer（侧边栏整理器）

一个纯前端插件（附带备份接口），在 ComfyUI 左侧工具栏新增一个 **「整理」** 标签页，
用于把左侧的**工作流（Workflows）** 和 **节点蓝图（Node Blueprints）** 归入自定义文件夹，
并可一键备份到本地目录。

- 版本：0.1.0　·　协议：MIT　·　环境：ComfyUI v0.33.x 新版前端（无 Python 依赖）

## 功能

- **创建文件夹**（支持重命名、删除，可无限层级嵌套**子文件夹**）
- **拖拽归类**：把工作流 / 蓝图直接拖进任意层级的文件夹，或拖回「未分类」
- **拖拽排序**：文件夹内的项目可拖拽调整顺序；文件夹可拖拽排序
  （拖到目标文件夹行**上半部 = 插入排序**，**下半部 = 移入该文件夹成为子文件夹**）
  **拖入画板**：把工作流或节点蓝图直接拖到画布上即可插入——
  工作流会整体插入为节点组合，蓝图会插入为子图节点
- **备份区**：选择一个本地目录，把工作流和节点蓝图快照备份到该目录
  （每次加载 / 退出 ComfyUI 自动备份，也可手动一键备份，自动保留最近 N 份）
- 双击工作流即可打开；右键菜单提供「移动到 / 重命名 / 删除」等操作

## 安装

**方式一：Git 克隆（推荐）**

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/xiake-1/comfyui-sidebar-organizer.git
```

**方式二：ComfyUI-Manager** —— Manager → Custom Nodes Manager → 搜索
`Sidebar Organizer`（或粘贴上面的 Git 地址安装）。

**方式三：手动复制** —— 把整个 `comfyui-sidebar-organizer` 文件夹放入
ComfyUI 的 `custom_nodes/` 目录。

安装后**重启 ComfyUI** 即可在左侧工具栏看到 **「整理」** 图标。无需安装任何
Python 依赖。

```
ComfyUI/custom_nodes/comfyui-sidebar-organizer/
├── __init__.py        # WEB_DIRECTORY 注册
├── backup.py          # 备份接口（目录选择 + 快照复制）
├── pyproject.toml     # 项目元数据
├── LICENSE
├── README.md
└── web/
    └── sidebar-organizer.js   # 前端扩展（整理器 UI）
```

## 使用

1. 启动 ComfyUI 后，在**左侧工具栏**最下方找到 **「整理」** 图标并点击。
2. 顶部按钮 `↻` 可刷新工作流列表（官方同步逻辑会清空蓝图条目，插件会自动恢复它们）。
3. 「工作流」区块：点击 `＋` 新建文件夹；拖动列表项到文件夹行上即归入该文件夹；
   在列表项之间拖动可调整顺序；拖到「未分类」即移出文件夹。
4. 「节点蓝图」区块：操作方式相同，管理的是你保存的子图蓝图（Subgraph Blueprint）。
5. 文件夹行右侧的 `⋮` 菜单可**新建子文件夹 / 重命名 / 删除**文件夹（删除文件夹时，
   其中的项目与子文件夹会移回上一级，不会被删除）。
   - 子文件夹可无限嵌套；「移动到」子菜单中会以缩进形式列出所有层级的文件夹。
   - 把文件夹拖到另一个文件夹行：**上半部** = 排序插入（同层级），**下半部** = 移入成为
     其子文件夹；把文件夹拖到「未分类」标题 = 移回根层级。不能把文件夹移入自身或
     它的子文件夹。
6. 列表项右侧的 `⋮` 菜单：
   - 工作流：**打开 / 移动到 / 重命名 / 删除**
   - 节点蓝图：**移动到 / 重命名 / 删除**
   - 位于文件夹中的条目还会显示 **移出文件夹**（直接移回「未分类」）
   - 重命名 / 删除会**同步操作实际文件**：工作流重命名会移动 `workflows/` 下的文件并
     自动迁移书签与缩略图；蓝图重命名会移动 `subgraphs/` 下的蓝图文件。
   - 重命名或删除蓝图后，节点库中的名称需要刷新页面才能同步；操作成功后插件会
     询问**是否立即刷新**（当前画布未保存的改动可能丢失，可选择「稍后再说」）。
   - 注意：重命名或删除蓝图会改变其节点类型，刷新页面后，之前已保存工作流中引用
     旧名称蓝图的节点会变为缺失节点（与官方「删除蓝图」行为一致），请谨慎操作。
7. **拖入画板**：按住任意工作流 / 蓝图条目，拖到中间的画布区域松手即可插入。
   - 工作流：整体插入到当前画布（与工作流页签右键「插入」行为一致）。
   - 节点蓝图：以子图节点形式插入，插入后自动选中。
   - 注意：如果拖拽后松手的位置在侧边栏内，仍是「归类 / 排序」操作；只有落在
     画布上才会插入。面板与工具栏区域不会误触发创建节点。
8. **备份区**（整理器最下方）：
   - 「选择文件夹…」弹出系统目录选择框；「手动输入…」直接粘贴完整路径。
   - 「立即备份」手动备份；右上角保留数量可调（默认保留最近 30 份，超出自动清理）。
   - **每次加载**（打开/刷新页面）与**每次退出**（关闭页面）时自动备份。
   - 备份内容：`user/<用户>/workflows/` 与 `user/<用户>/subgraphs/` 的完整快照，
     存放在 `<备份目录>/<时间戳>/` 下（含 manifest.json 清单）。
   - 备份目录设置在 `user/<用户>/sidebar-organizer/config.json` 中，换机器或重装后
     重新选择一次即可。

## 数据存储

- 整理结果（文件夹定义、项目归属与排序）保存在用户目录下的
  `user/<用户名>/sidebar-organizer/config.json`。
- **插件只改这份配置，不会移动、重命名或删除你的工作流 / 蓝图文件**，完全可逆：
  删除插件后，你的文件保持原样。

## 兼容性

- 前端：ComfyUI 新版前端（Vue）1.45.x（ComfyUI Desktop v0.33.x 自带）。
